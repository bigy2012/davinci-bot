# ฟังก์ชัน 3: B-roll / Insert อัตโนมัติ

เป้าหมายคือทุกครั้งที่พูดถึงคน สถานที่ เหตุการณ์ หรือสิ่งของ คนดูต้อง**เห็นสิ่งนั้น** และใช้ภาพช่วยเปลี่ยนจังหวะให้คลิปไม่น่าเบื่อ โดยทุกชิ้นต้องรู้ที่มาและสิทธิ์การใช้งาน

ผู้ใช้เป็นคนกำหนดงาน และต้องอนุมัติแผนพร้อมรายการไฟล์ที่จะดาวน์โหลดก่อนเสมอ

## ขั้นที่ 0: เช็คความพร้อม
- `resolve_status` ถ้า bridge ไม่ตอบ ให้บอกผู้ใช้ไปที่ Workspace → Scripts → DaVinci Bot Bridge
- ห้ามสลับโปรเจกต์ใน Resolve เอง

## ขั้นที่ 1: Brief (ถามเฉพาะข้อที่ยังไม่รู้ พร้อมค่าแนะนำ)

| ข้อ | ค่าแนะนำ |
|---|---|
| timeline | timeline ปัจจุบัน |
| ความถี่ | คลิปยาว: ทุก 6–10 วิ / คลิปสั้น: ทุก 2–4 วิ |
| ชนิดภาพ | ภาพจริง/ฟุตเทจเก่าสำหรับคน สถานที่ เหตุการณ์ + stock สำหรับเรื่องนามธรรม |
| มีม | ไม่ใส่ (fair use เสี่ยงกับช่องที่หารายได้) ใส่เมื่อผู้ใช้ขอเท่านั้น และไม่เกิน 1–2 ชิ้นต่อคลิป |
| layout | คลิปยาว: full + pip / คลิปสั้น: full + top (+ meme) |
| สิทธิ์ที่รับได้ | A (เสรี) + B (ให้เครดิต) / C เฉพาะเมื่อผู้ใช้ยอม |
| เครดิตบนจอ | ใส่ให้ภาพระดับ B/C (ตัวเล็กมุมซ้ายล่าง) + รวมไว้ใส่ในคำอธิบายคลิป |
| คลัง B-roll ของตัวเอง | ถ้ามีโฟลเดอร์ ให้ใช้ก่อน (`list_media_folder`, `export_frame_previews`) |

## ขั้นที่ 2: อ่านเนื้อหาพร้อมเวลา
- timeline ที่สร้างด้วย build_rough_cut/build_timeline: ใช้ `draft_captions(timeline, mode="long")` จะได้ประโยคพร้อมเวลาบน timeline
- ถ้าเป็นไฟล์: ใช้ `analyze_speech` หรือ `draft_captions(source_path=...)`

## ขั้นที่ 3: วางแผน beat
แบ่งเนื้อหาเป็นช่วงตามความหมาย แต่ละ beat ต้องมี: ช่วงเวลา, ประโยคที่พูด, ภาพที่ควรเห็น, คำค้นภาษาอังกฤษ 1–3 แบบ (เฉพาะเจาะจงก่อน แล้วกว้างขึ้นเป็นสำรอง), layout

**เลือกภาพอะไร**
- ชื่อคน สถานที่ วันที่ เหตุการณ์จริง → ภาพหรือฟุตเทจของจริง (archive, NASA, ภาพข่าวที่ CC) ห้ามใช้ภาพ "คนหน้าคล้าย" หรือภาพ AI ที่ทำให้เข้าใจผิดว่าเป็นเหตุการณ์จริง
- สิ่งของหรือการกระทำ → ภาพตรงตัว (ร่มชูชีพ, เครื่องบิน 727, เงินดอลลาร์)
- เรื่องนามธรรม (ความลึกลับ, การตามล่า) → ภาพเปรียบเทียบ (เงามืด, เอกสารลับ, แฟ้มคดี)
- มุกหรือประชด → มีม (ถ้าผู้ใช้อนุญาต)
- ตัดภาพที่มีลายน้ำ, ความละเอียดต่ำเกิน (full ควร ≥ 1280px, pip ≥ 640px), ข้อความภาษาอื่นที่ทำให้สับสน, คนทั่วไปที่ไม่เกี่ยวข้อง และภาพรุนแรง

**จังหวะ**
- 2 วินาทีแรก (hook) ให้เห็นหน้าคนพูด เว้นแต่ภาพแรงพอจะเป็น hook เอง
- B-roll แต่ละชิ้นยาว 1.5–4 วิ (meme 0.8–1.5 วิ) เริ่มพร้อมคำที่พูดถึงสิ่งนั้น หรือก่อนหน้า 0.1–0.2 วิ
- อย่าบังหน้าตอนพูดประโยคสำคัญหรือแสดงอารมณ์ ให้สลับระหว่างหน้าคนพูดกับภาพ
- ห้ามวางทับกัน (ชิ้นละช่วงเวลา) จะต่อกันได้ถ้าเป็นเรื่องเดียวกัน
- layout: full = จุดสำคัญ/เปลี่ยนฉาก, pip = ขยายความโดยยังเห็นคนพูด, top = คลิปแนวตั้ง, meme = มุก

## เอกสารจริง (ใช้ก่อนภาพ stock เสมอเมื่อเรื่องมีรายงานทางการ)
- ทุก `[เอกสาร: ... หน้า N — ไฮไลต์ "..."]` ในสคริปต์ และทุกจุดที่พูดตัวเลขหรือข้อสรุปจากรายงาน เป็นที่ที่ดีที่สุดสำหรับ insert แบบนี้
- ขั้นตอน:
  1. ใช้ `official_doc(source, "search", query=...)` หาหน้า
  2. ใช้ `official_doc(source, "text", page=N)` ตรวจบริบท
  3. ใช้ `official_doc(source, "image", page=N, highlight=["ประโยคตรงตามเอกสาร"], out_dir="~/Desktop/Agent-M/<เรื่อง>/docs")` ทำภาพไฮไลต์
- วางด้วย `place_broll` แบบ `{"path": <image>, "focus": <focus>, "layout": "full", "credit": "ที่มา: <หน่วยงาน>, <รายงาน> (ปี) หน้า N"}` จะเห็นทั้งหน้าก่อน แล้วซูมเข้าไฮไลต์ ใช้ความยาว **4–7 วินาที** ให้คนดูอ่านทัน
- ถ้า `not_found` แปลว่าข้อความในไฮไลต์ไม่ตรงกับเอกสาร ให้คัดลอกประโยคจาก `text` มาใหม่ ห้ามแต่งเอง
- ดาวน์โหลดเอกสารจาก URL ต้องให้ผู้ใช้อนุมัติก่อนเหมือนไฟล์อื่น

## ขั้นที่ 4: ค้นหาและเลือก
- `search_broll(query, kind)` ทีละ beat แล้ว Read `contact_sheet` เพื่อดูภาพจริงทุกครั้ง ห้ามเลือกจากชื่อไฟล์อย่างเดียว
- เลือก 1 ชิ้นต่อ beat + สำรอง 1 ชิ้น ถ้าหาไม่ได้ ให้ลองคำค้นที่กว้างขึ้นหรือเปลี่ยนเป็นภาพเปรียบเทียบ
- ระดับ C หรือสิทธิ์ที่ไม่ชัด ให้ตรวจหน้าต้นทาง (`page`) ก่อนเสนอ

## ขั้นที่ 5: เสนอแผน (รออนุมัติ)
| # | เวลา | พูดว่า | ภาพ (id) | แหล่ง / สิทธิ์ | layout | ความยาว |
|---|---|---|---|---|---|---|

ตามด้วย **รายการไฟล์ที่จะดาวน์โหลด** (ชื่อ, แหล่ง, ขนาดโดยประมาณ) แนบ path ของ contact sheet ให้ผู้ใช้ดู และรอคำอนุมัติ

## ขั้นที่ 6: ดาวน์โหลดและเตรียม
1. `fetch_broll(ids)` ดาวน์โหลดเฉพาะที่อนุมัติแล้ว ไฟล์ไปอยู่ใน `~/Movies/DaVinci Bot B-roll` พร้อม CREDITS.md
2. วิดีโอ: `export_frame_previews` เพื่อหาช่วงที่ดีที่สุดแล้วตั้ง `src_start`
3. `preview_broll(timeline, 2–4 ชิ้น)` แล้ว Read ดูว่าตรงเนื้อหาไหม การ์ดบังหน้าหรือเปล่า แล้วปรับ `layout`/`box`/`motion`

## ขั้นที่ 7: วางลง timeline
1. `place_broll(timeline, items)` จะวางบน track "B-roll" ใต้ Captions เสมอ ถ้าเรียกซ้ำจะแทนที่ทั้ง track ดังนั้นต้องส่งรายการครบทุกครั้ง
2. `open_page("edit")`
3. รายงานผล: จำนวนชิ้น, เวลาเรนเดอร์, และ `credits_for_description` สำหรับวางในคำอธิบาย YouTube
