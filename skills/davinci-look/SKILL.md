# ฟังก์ชัน 5: Look / แต่งหน้าใส

## preset ที่มี
`list_looks()` จะแสดงไฟล์ `presets/*.drx` ในโปรเจกต์ davinci-bot

**natural-skin**: ผิวเนียนใสแบบธรรมชาติ สร้างและวัดผลกับฟุตเทจห้องทำงานของผู้ใช้ (กล้อง DJI ตั้งนิ่ง ไฟส้ม)
- Qualifier เลือกโทนผิว (Hue 36.7 ±14, Sat 0–30, Lum 35–92) ส่วนผม คิ้ว ตา ซึ่งมืดกว่า Lum 35 จะไม่ถูกเลือก
- Power Window วงรีขอบนุ่มรอบบริเวณหัวกลางเฟรม เพื่อกันผนังสีเบจที่มีโทนเดียวกับผิวไม่ให้ถูกแก้
- Mid/Detail -55 + Blur 0.52 ทำให้รายละเอียดผิวลดลงประมาณ 17% แต่เนื้อผิวยังอยู่
- Gamma +0.03 ให้ผิวสว่างขึ้นประมาณ +8/255 ดูใส และ Saturation 46 ลดความแดงและความหมองเล็กน้อย
- ทำงานในเวอร์ชันฟรีได้ เพราะไม่ใช้ Face Refinement หรือ Beauty ซึ่งเป็นของ Studio

**natural-skin-tone (.cube LUT)** มี 3 ระดับ: `-light` / ปกติ / `-strong`
- เป็นเวอร์ชัน "ผิวใสอย่างเดียว" ไม่มีผิวเนียน เพราะ LUT เปลี่ยนได้แค่สี ทำงานกับพิกเซลรอบข้างหรือตำแหน่งในภาพไม่ได้
- เลือกผิวจากมุมสี YCbCr (ผิว 113–120° / ผนัง 134–151°) ผนังจึงแทบไม่เปลี่ยน
- แก้มสว่างขึ้น +3.6 / +6.4 / +10.2 (จาก 255) ตามระดับ
- ใช้ได้ทั้ง Resolve (ติดตั้งในหมวด LUT "davinci-bot" แล้ว) และ CapCut (ไฟล์อยู่ที่ `~/Desktop/Agent-M/LUTs/`)
- ห้ามใช้ซ้อนกับ natural-skin.drx เพราะจะสว่างซ้ำสองชั้น
- สร้างใหม่หรือปรับได้ด้วย `davinci_bot/lut.py` (strength, lift, desat, warm_shift)
- ทำมาสำหรับฟุตเทจโปรไฟล์ปกติ (Rec.709) ถ้าถ่ายเป็น D-Log ต้องแปลงสีก่อน

## ขั้นตอน
1. `resolve_status` และห้ามสลับโปรเจกต์เอง
2. `preview_look(timeline, look, at)` เลือกวินาทีที่เห็นหน้าชัด แล้ว Read ภาพเทียบ ก่อน | หลัง เพื่อเช็คว่า:
   - ผิวเนียนขึ้นแต่ยังเห็นเนื้อผิว ไม่เป็นผิวพลาสติก
   - ตา คิ้ว ผม และแว่นยังคม
   - ผนังหรือพื้นหลังไม่เปลี่ยน และไม่มีขอบวงรีให้เห็น
3. ส่ง path ภาพเทียบให้ผู้ใช้ดูและรออนุมัติ
4. `apply_look(timeline, look)` ใส่ให้ทุกคลิปบน V1 (จะแทนที่เกรดเดิมของคลิปเหล่านั้น)
5. ถ้าผู้ใช้ไม่ชอบ ให้ใช้ `reset_look(timeline)`

## เมื่อ preset ไม่เข้ากับฟุตเทจ
natural-skin ทำมาสำหรับมุมกล้องและแสงชุดนี้ ถ้าถ่ายที่อื่น เปลี่ยนแสง หรือคนไม่ได้อยู่กลางเฟรม เช่น วงรีไม่ครอบหน้า สีผิวไม่ถูกเลือก หรือผนังถูกแก้ไปด้วย ให้แจ้งผู้ใช้และเสนอทำ preset ใหม่สำหรับชุดนั้นในหน้า Color ตามขั้นตอนนี้:
1. ใช้ Qualifier ดูดสีที่แก้มและหน้าผาก แล้วขยายช่วง (Hue width ~14, soft 8; Sat high ~30; Lum low ~35)
2. เพิ่ม Window วงรีครอบบริเวณที่หัวขยับ (ขอบนุ่ม 12)
3. ตั้ง Mid/Detail -55, Blur 0.52, Gamma +0.03, Saturation 46
4. วัดผลด้วย export_frame ก่อน/หลัง แล้ว `save_grade` ไปที่ `presets/<ชื่อ>.drx`

ความแรงที่ปรับได้: ถ้าเบาลงใช้ Blur 0.51 / Mid/Detail -35 / Gamma +0.02 ถ้าแรงขึ้นใช้ Blur 0.53–0.54 / Mid/Detail -70 ไม่ควรเกิน Blur 0.54 เพราะผิวจะเริ่มดูเป็นพลาสติก
