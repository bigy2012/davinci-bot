2ติดตั้ง (ทำครั้งเดียว)

เครื่องนี้ติดตั้งครบแล้ว ใช้ส่วนนี้เมื่อย้ายเครื่องหรือต้องติดตั้งใหม่

ต้องมี DaVinci Resolve 21, uv, ffmpeg, whisper-cli และโมเดล Whisper large-v3 จากนั้นรันในโฟลเดอร์โปรเจกต์:

cd ~/Desktop/Project/davinci-bot
./install_bridge.sh          # ใส่ Bridge ลงเมนู Scripts ของ Resolve
uv sync                      # ติดตั้ง library ของ Python
claude mcp add --scope user davinci-bot -- uv run --directory "$PWD" server.py
ln -s "$PWD/skills/davinci-rough-cut" ~/.claude/skills/davinci-rough-cut

ตรวจว่าเชื่อมต่อแล้ว:

claude mcp get davinci-bot   # ต้องขึ้น ✔ Connected

★หน้าเว็บ / แอป Mac

สั่งงานผ่านหน้าเว็บแทนการพิมพ์ใน Claude Code

  1. 1

    เปิดแอป

    ดับเบิลคลิก DaVinci Bot ใน ~/Applications (ลากไปไว้ที่ Dock ได้) เบราว์เซอร์จะเปิดหน้า 127.0.0.1:8765 ให้เอง

  2. 2

    ดูแถบสถานะ

    จุดสีเขียว = Resolve พร้อม (แสดงโปรเจกต์และ timeline), สีเหลือง = กำลังทำงาน, สีแดง = ยังไม่ได้เปิด Bridge

  3. 3

    สั่งงาน

    เลือกการ์ดฟังก์ชันทางซ้าย กรอกฟอร์มแล้วกด "เริ่ม" หรือพิมพ์คำสั่งในช่องแชท ภาพตัวอย่าง เสียงตัวอย่าง และรายงานจะแสดงในแชทเลย

  4. 4

    อนุมัติเมื่อถูกถาม

    คำสั่งที่เสี่ยง เช่น รันคำสั่งระบบ เขียนไฟล์ หรือดาวน์โหลด จะขึ้นกล่องให้กด "อนุญาต" หรือ "ไม่อนุญาต" ทุกครั้ง

ปุ่ม "หยุด" ใช้สั่งหยุดกลางคัน, "แชทใหม่" เริ่มแชทใหม่ (แชทเดิมถูกบันทึกไว้) และ "ปิดแอป" ปิดเซิร์ฟเวอร์ แอปทำงานในเครื่องคุณเท่านั้น

ประวัติแชท

  • แท็บ "ประวัติแชท" ทางซ้าย: ค้นหา, เปลี่ยนชื่อ (✎), ลบ (🗑)
  • คลิกแชทเก่าเพื่อเปิดแล้วคุยต่อได้เลย Claude จำบริบทเดิมทั้งหมด เช่น "ซับอันที่ 12 แก้คำว่า…"
  • วางเมาส์บนข้อความที่เคยส่ง แล้วกด "✎ แก้ไขแล้วส่งใหม่" จะได้แชทแขนงใหม่ที่เริ่มจากจุดนั้น ส่วนแชทเดิมยังอยู่ครบ

4ฟังก์ชัน 1: Rough Cut (ลัพคัท)

ตัดช่วงเงียบ คำซ้ำ และที่พูดผิด เลือกเทคที่ดีที่สุด แล้วต่อให้ฟังเหมือนพูดรอบเดียวจบ

ตัดออกเสมอ

  • slate, นับถอยหลัง, "แอคชั่น"
  • ช่วงเงียบที่ไม่มีประโยชน์
  • ประโยคที่พูดไม่จบแล้วเริ่มใหม่, คำติดอ่าง
  • คำเติม เช่น เอ่อ อ่า อืม
  • ข้อมูลที่พูดผิดแล้วแก้ทีหลัง (เก็บเฉพาะเวอร์ชันที่ถูก)
  • พูดนอกบท เช่น "ปีไหนนะ"

เลือกเทคที่ดีที่สุด

  1. ครบ: ประโยคจบสมบูรณ์
  2. ถูก: เนื้อหาเป็นเวอร์ชันที่แก้แล้ว
  3. ลื่น: ไม่ติดขัด
  4. เข้ากัน: น้ำเสียงต่อกับประโยครอบข้างได้
  5. ถ้าเสมอกัน ใช้เทคหลังสุด

จังหวะ (pace)

คือระยะที่เผื่อไว้ก่อนและหลังคำพูดของแต่ละช็อต ซึ่งเป็นตัวกำหนดว่าช่องว่างระหว่างประโยคจะยาวแค่ไหน

paceเผื่อหน้าเผื่อหลังเหมาะกับ
tight0.05 วิ0.10 วิShorts, เล่าเรื่องเร็ว
natural0.10 วิ0.25 วิคลิปยาวทั่วไป (ค่าเริ่มต้น)
relaxed0.15 วิ0.45 วิสารคดี, อารมณ์ช้า
ผลทดสอบกับฟุตเทจจริง (ไฟล์ DJI_…0016): จาก 2:31 นาทีเหลือ 29.4 วินาที 17 ช็อต ประโยค "ไปติดตามกันใน…" ที่พูดใหม่ 9 รอบเหลือแค่รอบที่ดีที่สุด

อยากเปลี่ยนกฎก็แก้ได้ที่ skills/davinci-rough-cut/SKILL.md ซึ่งเขียนเป็นภาษาไทย

5Jump / J / L cut คืออะไร

ระบบวางเสียงต่อกันเสมอ แล้วขยับเฉพาะจุดตัดภาพ (V1 = ภาพ, A1 = เสียง)

ภาพ (V1)เสียง (A1)
แบบใช้เมื่อสั่งยังไง
Jump cutค่าเริ่มต้น ใช้ระหว่างชิ้นที่เป็นความคิดเดียวกัน"ตัดชนธรรมดา"
Punch-inซูมสลับ 100% / 110% ทุกช็อต ทำให้ jump cut กล้องเดียวดูตั้งใจ"ใส่ punch-in 110%"
L cutตอนจบประโยคแล้วขึ้นประโยคใหม่ ทำให้รอยต่อนุ่ม"ใช้ L-cut ตอนขึ้นประโยคใหม่"
J cutคำตอบหรือการเปลี่ยนเรื่อง ต้องมีช่วงเงียบก่อนประโยคถัดไปพอ ไม่อย่างนั้นจะเห็นปากขยับไม่ตรงเสียง"ใช้ J-cut ตอนเปลี่ยนหัวข้อ"

6ฟังก์ชัน 2: ซับไตเติลภาษาไทย

ซับตามบริบท ไม่ล้นจอ ไม่บังหน้า มี 2 แบบตามประเภทคลิป

คลิปยาว: clean

กลางล่างจอ ตัวขาวขอบดำและมีเงา บรรทัดละไม่เกิน 38 ตัวอักษร ใส่ลง subtitle track ของ Resolve แก้ข้อความใน Resolve ได้ และส่งไฟล์ .srt ขึ้น YouTube ได้

คลิปสั้น: pop / karaoke / box

  • pop: ซับเด้งเข้า คำที่กำลังพูดเป็นสีเหลืองและขยาย คำเน้นเป็นสีแดง
  • karaoke: คำค่อยๆ สว่างขึ้นตามเสียง สไลด์ขึ้น
  • box: ตัวอักษรบนกล่องสี สลับสีทุกซับ

ซับละ 1 บรรทัด ไม่เกิน 16 ตัวอักษร เรนเดอร์เป็นคลิปใส 1 ไฟล์ต่อ 1 ซับ วางบน track "Captions"

  1. 1

    สั่ง

    "ใส่ซับให้ timeline roughcut v1 แบบ pop" (บอกชื่อคน ชื่อสถานที่ หรือตัวเลขที่ต้องสะกดให้ถูกด้วยได้)

  2. 2

    Claude ร่างและตรวจแก้คำ

    ถอดเสียง แบ่งคำไทยไม่ให้ขาดกลางคำ แก้คำที่ Whisper ฟังผิดตามบริบท แล้วเลือกคำที่จะเน้นด้วย *คำ*

  3. 3

    ดูภาพตัวอย่างบนเฟรมจริง

    ภาพแสดงซับบนวิดีโอของคุณ ส่วนคลิปแนวตั้งจะมีแถบแดงบอกพื้นที่ที่ปุ่มของ Shorts/TikTok จะบัง ถ้าอยากเลื่อน ขยาย หรือเปลี่ยนสีก็สั่งได้

  4. 4

    อนุมัติ แล้วซับจะลง timeline

    ถ้าอยากแก้ทีหลัง ให้สั่งเรนเดอร์ใหม่ ระบบจะแทนที่ track "Captions" เดิมทั้งหมด

ภาพหรือการ์ดโผล่pop, camera-shutter, typingตอนการ์ด/มีมเด้งเข้า
ลุ้น / อยากดูต่อเสียงที่ค่อยๆ ดังขึ้นแล้วไปจบตรงจุดเฉลย, เพลงเงียบลงก่อนเฉลยก่อนเฉลยและประโยคปิด

ตรงจังหวะพอดี

ระบบวัดว่า SFX แต่ละไฟล์กระแทกที่วินาทีไหน (เช่น vine-boom กระแทกที่ 0.36 วิ) แล้ววางให้จุดกระแทกตรงกับคำพอดี และให้จุดที่เพลงพุ่งตรงกับจุดหักมุมของเรื่อง

เสียงพูดชัดเสมอ

เพลงลดลงประมาณ 8–10 dB ตอนพูดแล้วดังขึ้นตอนเงียบ (ducking) ส่วน SFX ถูกปรับความดังเทียบกับเสียงพูด มี 4 ระดับ: loud / normal / soft / subtle

เรื่องโศกนาฏกรรมจริง (MH370, ซารินโตเกียว, น้ำท่วม) จะไม่ใส่ SFX ตลกหรือมีม ใช้เฉพาะเสียงตึงเครียดและ impact เบาๆ
  1. 1

    สั่ง

    "ใส่เพลงกับ SFX ให้ timeline roughcut v1 แนวลุ้นๆ มีตบมุกนิดหน่อย"

  2. 2

    ตรวจแผน + ฟังตัวอย่าง

    ได้ตาราง เวลา / ประโยค / เสียง / เหตุผล พร้อมไฟล์ mp3 ที่มิกซ์แล้วให้กดฟัง

  3. 3

    อนุมัติ แล้วเสียงจะลง timeline

    วางบน audio track "Music" และ "SFX" ถ้าอยากแก้ก็สั่งได้ เช่น "เอา boing ออก" หรือ "vine-boom ดังไป"

9ฟังก์ชัน 5: แต่งหน้าใส (natural-skin)

  • เลือกเฉพาะผิว (ผม คิ้ว ตา ไม่ถูกแตะ)
  • วงรีขอบนุ่มรอบหัว กันไม่ให้ผนังสีเบจโดนแก้ไปด้วย
  • ลดรายละเอียดผิวประมาณ 17%: จุดและรูขุมขนจางลง แต่ยังเห็นเนื้อผิว
  • ผิวสว่างขึ้นเล็กน้อยและลดความแดง ดูใสขึ้น

10ฟังก์ชัน 6: วิเคราะห์ Creator

หาเสน่ห์ จุดเด่น จุดด้อย และแนวทางต่อไป โดยทุกข้อมีหลักฐานจากงานจริง

วัดจากฟุตเทจ

  • เวลาที่พูดจริงเทียบกับเวลาอัด และสัดส่วนการพูดซ้ำ
  • ความเร็วพูด และช่วงเสียงสูงต่ำ (ความมีชีวิตชีวา)
  • ความสะอาดของเสียง
  • ความล้าระหว่าง session
  • เฟรมตัวอย่าง: แสง, สายตา, การวางตัวในเฟรม

อ่านจากสคริปต์และแบรนด์

  • ความยาวเทียบกับแผน, hook, โครงเรื่อง, ปมที่วางไว้แล้วเฉลย
  • การแก้สคริปต์หลังอัด
  • โลโก้, intro, องค์ประกอบที่ซ้ำทุกตอน
  • ข้อมูล YouTube Studio (ถ้าส่ง CSV มา)

โหมดโค้ช: ขอ "วิธีแก้และวิธีฝึก" จะได้แผนฝึก 4 สัปดาห์ จากนั้นส่งไฟล์อัดฝึกมาว่า "practice feedback ไฟล์ ..." จะได้ผลเทียบกับค่าเดิมและเป้าหมาย พร้อม % ที่พูดตรงบท

สั่งว่า "วิเคราะห์ creator ให้หน่อย" จะได้รายงาน .md ใน reports/ ซึ่งมีสรุป, เสน่ห์, จุดเด่น, จุดด้อย, ตัวเลข, แนวทาง 3 ระยะ, แผน 30 วัน และ KPI

11ฟังก์ชัน 7: เขียนสคริปต์ → Teleprompter

ใช้ skill action-story-channel-script ของคุณเป็นกฎการเขียน แล้วต่อเข้ากับงานอัดและตัดต่อ

เขียน / ปรับสคริปต์

  • ใช้กฎจาก skill ของคุณเวอร์ชันล่าสุดเสมอ (ชุดที่ sync จาก claude.ai)
  • บันทึกที่ Agent-M/<เรื่อง>/<topic>_script_vN.md โดยไม่เขียนทับเวอร์ชันเดิม
  • ความยาวค่าเริ่มต้น = ไม่จำกัด ยาวตามความเข้มข้นของเรื่อง แต่ห้ามยืด (re-hook ทุก 5–8 นาที, ไม่พูดซ้ำ, recap สั้นทุก 15–20 นาที, มี chapters และจุดวางโฆษณา)
  • ถ้ากำหนดความยาว จะเทียบกับงบ: 20 นาที ≤ ~9,500 / 25 นาที ≤ ~12,500 / 30 นาที ≤ ~15,500 ตัวอักษร (นับแบบ wc -m)

Teleprompter

  • ดึงเฉพาะบทพูด ตัดบรรทัดตามจังหวะหายใจ ตัวเลขเป็นตัวหนาสีเหลือง
  • Space = เริ่ม/หยุด, ↑↓ = ความเร็ว, +/− = ขนาดตัวอักษร, M = กลับด้านสำหรับกระจก
  • ไฟล์ <เรื่อง>_prompter.html เปิดบนแท็บเล็ตหรือจอใต้เลนส์ได้เลย

สั่งว่า "เขียนสคริปต์เรื่อง …" หรือ "ทำ teleprompter จากสคริปต์ …" หรือใช้การ์ด 7 ในหน้าเว็บ
